# Project status

See [README](../README.md) for setup, [design notes](design.md) for the implementation,
and [release review](release-review.md) for the public-release audit.

The app is an offline, sideloaded widget. Ads and billing were removed. Location experiments
remain disabled. Both build types retain debug signing and the existing application ID.

Further work includes a device smoke test, home-screen ranking quality, a real dark theme,
and a separate decision about licensing or signed binary distribution. Personal device
measurements and machine-specific setup diaries are intentionally not published here.
